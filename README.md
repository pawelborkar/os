# HTML Trackers

This folder contains a set of standalone, mobile-responsive HTML trackers plus a landing hub that links them together at `https://os.pawel.in/`.

Files:
- `index.html` — landing hub with quick-link cards and topic index for every tracker
- `interview-questions.html` — JavaScript, React, Machine Coding, DSA, Python, FastAPI, PostgreSQL, Applied AI/RAG, and System Design interview practice
- `ai-product-engineer.html` — six-week AI product engineer startup job-search and DevPulse shipping roadmap
- `auth.html` — authentication mastery checklist covering JWT, refresh token rotation, password hashing, and security pitfalls
- `backend.html` — ten-week backend mastery roadmap for FastAPI, PostgreSQL, SQLAlchemy 2.0, Docker, and project delivery
- `workout.html` — seven-day recomposition workout tracker with exercise timers, rest timers, and weekly history
- `robots.txt` & `sitemap.xml` — crawler directives and canonical sitemap for `os.pawel.in`
